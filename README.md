# Scenic-results

<!-- badges: start -->

<!-- badges: end -->

This repo has the data and scripts needed for performing marker gene and marker peak enrichment on the target genes and target regions of regulons predicted by SCENIC+ The directories contain the following files:

-   `data`: The direct eRegulons predicted by SCENIC+ for SC,DE,S2 stages

-   `functions:` All functions needed to run the scripts

-   `scripts`: Scripts for gene enrichment and peak enrichment
